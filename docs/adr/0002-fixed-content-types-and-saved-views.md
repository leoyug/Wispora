# 2. 固定内容类型与可编辑快捷视图

Date: 2026-09-06

## Status

Accepted

## Context

原模型使用“频道”同时表达网页、文章、关注对象、设计主题、工具用途与未读状态。这些维度的稳定性、交互和卡片表现不同，放入同一结构后无法清楚解释筛选结果。

## Decision

收藏项使用三种固定内容类型：网站、文章和关注源，用户不能新增类型，但可以将已有收藏项重新归入这三种类型之一。主题、风格、技术和用途使用可编辑标签表达。侧栏负责选择全部、未处理、星标或一种内容类型；顶部只提供标签筛选、排序和排列入口，避免用两套控件表达相同范围。

快捷视图保存一个侧栏范围与一组标签，用于恢复常用查找条件。排序方式、排列样式、搜索词、搜索字段和收藏时间条件不属于快捷视图；从侧栏调用快捷视图时使用默认的“最新”排序，关键词、时间与字段继续保留。切换侧栏范围会清空临时标签并恢复默认排序。

2026-10-27 搜索二期补充（历史行为，后续搜索边界以下方最新修订为准）：搜索面板可以在草稿中替换同一个范围值，以便连续缩小或扩大查找范围；不增加类型与状态的交叉组合，也不在常驻工具栏重复放范围控件。原交付中面板内切换范围保留草稿标签，只有显式提交才同步侧栏。直接侧栏导航仍清空临时标签并恢复最新排序，保留关键词与搜索字段；快捷视图仍只保存范围与标签 ID，不保存搜索字段。范围或标签改变后解除原快捷视图关联，仅改变关键词或搜索字段可以保留关联。

2026-10-28 搜索修订（历史呈现，单范围边界保留）：面板的范围缩为全部收藏、网站、文章、关注源四个并列单选项，不再提供星标、未处理或视觉分组标题；侧栏仍保留这两个状态范围。从星标或未处理打开搜索时，草稿从全部收藏开始，取消后仍保留原工作台状态。旧状态范围搜索历史保留在存储中，但不作为面板可恢复选项，避免恢复不可见的状态限制。范围本身不计入额外筛选数；多选字段属于关键词匹配约束，仍不进入快捷视图保存边界。

2026-10-28 精确标签简化（历史行为，已由下述 Figma 修订替代）：面板只保留范围与搜索字段，“标签”作为关键词匹配字段，不再提供精确标签选择。打开面板和恢复旧搜索历史均不带入精确标签条件，取消仍保留原工作台标签；显式提交清空工作台标签，原快捷视图包含标签时解除关联。范围未变且原本无标签的快捷视图仍可在仅改变关键词或字段时保留关联。工作台工具栏、URL 和快捷视图继续使用稳定标签 ID 进行精确组合筛选，快捷视图的保存边界不变。原次证据见[精确标签简化记录](../design/command-search-tag-simplification-2026-10-28.md)。

2026-10-28 Figma 三态修订：搜索按默认记录、独立筛选、条件与结果三个状态呈现。类型胶囊可取消地单选网站、文章或关注源，无选中即全部；不增加类型与星标／未处理的交叉组合。打开时复制工作台生效标签、关键词、时间和字段，状态范围仍转换为全部。筛选页恢复稳定标签 ID 多选 AND，并增加一个按本地收藏日期计算的可取消时间范围；字段未限定或选满五项即全部。最近搜索和 URL 恢复这些可见约束，显式提交应用完整草稿，取消保留原上下文。原次还在搜索中展示快捷视图，该入口由下述用户反馈修订移除；关联和保存边界保留。

2026-10-28 八点反馈修订（当前决定）：搜索筛选只显示类型、时间、标签和字段，不重复提供快捷视图组；快捷视图继续从侧栏调用。原工作台视图关联仍可随草稿复制，手动改范围或标签立即解除标记，提交时仅保留范围和标签仍与草稿一致的视图。仅改关键词、时间或字段不改变视图定义，时间与字段不进入保存边界。搜索中的 `#` 只是候选和条件的显示前缀，不改变标签名称或身份。当前行为见[搜索方案](../design/command-search.md)。

“收藏”不再表示把链接带入灵感库；后者统一称为“添加”。卡片上的主动临时标记统一称为“星标”，用于当前工作中快速找回少量卡片。

## Consequences

- 左侧导航可以稳定地展示全部、未处理、星标、三种内容类型与快捷视图。
- 内容类型不能由用户新增，但标签和快捷视图可增删、重命名和排序。
- 收藏项改为另一种内置内容类型后，系统按新类型重新排入 AI 整理；用户描述与手动调整的标签仍优先。
- 网站、文章与关注源可以使用不同卡片结构，不再通过标签假装类型。
- 顶部筛选栏不会重复提供内容类型、处理状态或星标状态选项。
- 快捷视图的结果顺序可以临时调整，不会因此改变已保存的视图定义。
- 未读、AI 待处理和导入来源成为独立字段或筛选条件。
- 原有的“频道”术语与 `channelIds` 数据结构被废弃。
