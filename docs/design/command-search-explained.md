# 搜索栏改版，用起来会是什么感觉

日期：2026-10-27\
这是[搜索设计方案](command-search.md)的通俗说明。一期已在 `codex/command-search` 分支实现，并通过自动化检查与独立复核；详细筛选和最近记录属于尚未实现的二期。[查看一期运行截图与验收记录](command-search-phase-one-validation.md)。

## 先快速找，再慢慢缩小范围

首页还是保留一个简洁的搜索入口。你点击它，或者按 `⌘K / Ctrl+K`，会出现一个像你发的前三张图那样的搜索面板，光标已经在输入框里，可以直接打字。

一期先做好打开、输入和查看结果；二期再在未输入时给你看最近搜过的条件和最近打开的收藏项，方便回到刚用过的内容。

比如你输入“配色”，文字立刻出现，停顿约 0.2 秒后开始查找，随后展示最相关的几条结果。每条除了名称，还会显示已有描述。即使标题里没有“配色”，只要描述或保存的正文里出现过，也有机会找到。二期再补充命中文字的片段与高亮，让你更容易看出为什么找到它。

## 记不清名字，就点“筛选”

二期增加“筛选”按钮，点开后像你发的最后一张图一样，把查找条件按组展开：

- **范围**：全部收藏单独一项，网站、文章、关注源放在“内容类型”一组，星标、未处理放在“状态”一组。两组之间也只能选一个，和侧栏里的范围一致，暂时不能组合成“星标里的文章”。
- **搜索字段**：常用选项只有“全部字段、标题及描述、标签”。如果你确定那句话只写在描述里，可以从“更多字段”选择“仅描述”；域名、正文等低频选项也在更多里面。
- **标签**：选择你记得的标签，例如“动效”。选多个时，结果必须同时带有这些标签。

你可以先输入，再加条件；也可以先选标签，不输入任何词，直接找一组内容。已经选的条件会清楚显示，随时可以拿掉一个，不用全部重新来。

例如，你想找“描述中提到配色、带有设计工具标签的网站”：选择“网站”，从更多字段选“仅描述”，勾选“设计工具”标签，再输入“配色”就可以。提交后首页入口会同时显示“配色”和“筛选 3”，提醒你条件仍然存在。

## 找到一个就打开，想多比较就看全部

搜索面板先给你看最相关的 8 条。点击某一条或按 Enter 只是预览详情，不会改变工作台的搜索条件。关闭详情会回到搜索面板，刚才输入的词、选过的条件和看到的位置都还在，可以接着比较另一条。

如果你更习惯看封面，或者想比较更多内容，就点“查看全部结果”，也可以按 `⌘Enter / Ctrl+Enter`。这时才把关键词和筛选条件一起应用到工作台，你继续用原来的卡片或列表浏览。按钮旁保留快捷键提示，窄屏也能找到它。

在搜索面板中按 Esc 或点关闭，就回到打开前的工作台。单纯瞟一眼某条收藏，不会把原来的工作台突然改成另一套条件。更新结果时先显示“正在更新…”，不会把旧数量误报成当前结果。

## 和现在相比，最有价值的变化

以前是输入关键词后，直接在页面里找结果。改版后，你可以先看最近记录、快速预览，再根据线索一点点缩小范围；搜索结果也会优先把更相关的内容放在前面，较早添加的好内容更容易被找到。

实施分两步：先把打开、搜索、预览、查看全部和取消做完整，并保留已有的相关性顺序；再增加筛选、最近记录和命中片段。第一步完成就能独立使用。

外观上借鉴参考图的紧凑列表和清楚分组，同时保留 Wispora 现有的暖灰、品牌橙以及明暗主题。标签仍然不带 `#`，内容类型仍然是网站、文章、关注源。

它仍然搜索你本地已经保存的文字，不需要 AI，也不会自动理解一句模糊需求。“配色”和“颜色”暂时不会自动当作同一个意思；这次先把关键词查找和筛选配合做好。
