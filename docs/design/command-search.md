## 当前决定与参考来源

搜索面板分为默认记录、独立筛选、条件与结果三个状态。输入后先快速找，记不清名称时进入筛选页；返回结果页后逐项移除条件，再通过“查看全部结果”进入完整工作台。编辑控件与条件摘要不在同一视图重复出现。

## 搜索入口与面板

工作台入口继续复用按钮语义的 `SearchTrigger`，桌面参考 `560px × 52px`，点击或 `⌘K / Ctrl+K` 打开搜索并聚焦输入。有关键词时显示关键词；同时存在筛选时显示非交互的“筛选 N”。N 计精确标签数、非全部字段选项数和一个非默认时间条件，不计关键词或侧栏范围。窄屏优先省略关键词、隐藏快捷键，保留条件数；入口只反映已提交条件。

面板复用 Intent UI Command Menu 适配层的 Modal、Dialog、Autocomplete、SearchField 与 Menu。桌面宽 `708px`，灰色外框为 `1px border-subtle`；顶部距离 `clamp(64px, 12dvh, 128px)`，最大高度为 `min(80dvh, 100dvh - 80px)`。默认记录页与筛选页通过共享 `CommandMenu heightMode="stable"` 固定为同一 `480px` 默认高度，超出内容只在中间滚动；短窗口按视口上限收缩，两态仍保持相同高度。实际搜索结果使用 `heightMode="content"`，从 `480px` 下限按内容长至原最大高度。内部 Dialog 扣除上下共 `2px` 边框，输入栏与底栏固定；空态填充并居中。

- 输入栏固定高 `56px`、左右留白 `20px`，同一行放搜索图标、输入框、只清词的 X 与筛选按钮。输入为 `16px / 20px / 500`，沿用界面混排字体。
- 中间是唯一纵向滚动区域。筛选页或默认／结果内容互斥，不创建第二层 Modal。
- 默认与结果页固定底栏最小高 `64px`，左侧为选择、预览和可点击的 Esc 关闭，右侧为“查看全部 N 条”及平台提交快捷键。“查看全部”恢复共享 sm 的 `32px` 高、`0 11px` 内边距和 `12px` 内容间距，文字 `14px / 400`；关闭操作保持 `36px`。提交内快捷键使用共享 `24px` 高、`12px` 字号、`6px` 按键间距和 `0 8px` 内边距。更新或失败时不显示旧数字。
- 筛选页不渲染结果及计数，固定底栏提供取消与确定，沿用结果底栏高度。取消使用共享 secondary，确定使用 contrast；按用户截图中的“取消”统一为 sm：最小宽 `64px`、高 `32px`、文字 `14px / 500`、左右内边距 `11px`，按钮间距 `12px`（窄屏至少 `44px`）。顶部筛选入口再次点击等同取消。

  最新批注要求文字稍加重，两枚按钮从 400 调至 medium 500，其余几何与流程不变。13 项浏览器检查、`pnpm check`（类型检查、111 项测试、生产构建）及独立界面复核通过（ship）。三张最新截图在忽略的 `.impeccable/review/search-filter-button-medium-2026-10-29/`；测试会话与开发服务已关闭并复查退出。

  上一轮曾按通用确认弹窗默认值改为 `56×36px / 600`；用户随后明确要求以截图“取消”按钮为准，该方向已撤回。上一轮 11 项浏览器验证及截图仅作历史记录，位于忽略的 `.impeccable/review/search-filter-button-standard-2026-10-29/`，不再作为当前尺寸目标。

  尺寸参考修订（400 字重阶段）通过 `pnpm check`（类型检查、111 项测试和生产构建）及 13 项专项浏览器检查：两枚按钮桌面均为 `64×32px`、`14px / 400`、左右内边距 `11px`，按钮间距 `12px`；窄屏均为 `64×44px`。确定／取消及结果页按钮保持可用。本轮三张截图在忽略的 `.impeccable/review/search-filter-button-reference-2026-10-29/`；测试浏览器、控制进程和开发服务已正常关闭并复查退出。
- 宽度低于 `640px` 或高度不超过 `600px` 时，面板距视口 `12px`，输入与顶底栏按钮目标至少 `44px`，底栏最小高 `68px`。窄屏隐藏冗长导航提示和结果类型，保留关闭、提交及提交快捷键。

结果页可移除条件按用户最新截图使用中性 `surface-secondary / muted`、`0.5px border-default`，不再使用主色选中表面；筛选面板控件的选中态仍为 `accent-soft / accent-ink`。删除图标复用 `16px` 圆形视觉区和 `13px` Remix Close，悬停及胶囊键盘聚焦时使用 `surface-muted / ink`，按下有 `1px` 位移反馈。整个胶囊仍可点击或通过 Enter／Space 移除对应条件，随后回焦输入；没有新增颜色 token。

本轮验证：`pnpm check` 通过类型检查、111 项测试及生产构建；16 项浏览器检查覆盖深浅主题中性配色、局部悬停／按下／键盘焦点、精确移除与输入回焦、窄屏及编辑控件主色保留。五张截图保存在忽略的 `.impeccable/review/search-neutral-criteria-2026-10-29/`；独立界面复核为 ship。测试浏览器与开发服务已正常关闭并复查退出。

## 三个内容状态

| 状态 | 进入条件 | 显示内容 |
| --- | --- | --- |
| 默认记录 | 没有关键词、具体类型、时间或精确标签；仅限定字段仍属此态 | 最多 3 条最近搜索和最多 4 条真实最近打开；无记录时隐藏对应分组 |
| 独立筛选 | 点击顶部筛选按钮 | 筛选标题及紧随的字段说明、常驻清空操作（无条件时禁用）、类型／时间／标签／搜索字段四组；不重复显示摘要和结果；固定底栏提供取消／确定 |
| 条件与结果 | 有关键词、具体类型、时间或标签，且不在筛选页 | 有条件时显示可移除 Badge 与数量，随后显示完整结果数和最多 8 条预览；纯关键词查询没有空条件区 |

最近打开只显示实际有 `lastOpenedAt` 的收藏项。正常默认页不再重复显示“输入关键词开始查找”；加载、更新、失败及实际结果统计仍保留。没有历史不制造占位记录，收藏库为空时显示“还没有收藏项”。已归档内容不进入搜索。

结果使用真实 favicon、标题、域名、描述或命中片段，右侧显示内容类型。标题为 `16px / 22px / 500`，片段为 `14px / 20px / 400`，元数据为 `12px`。只有前 8 条按需提取命中片段；正文和标签命中注明来源。实际命中文字以 `search-match-text`、`accent-soft` 和 `650` 字重共同强调，不拼接 HTML。外部检索已完成匹配，Autocomplete 不按标题再次过滤。

## 筛选四组

最近打开、最近搜索、筛选标题、条件摘要与结果统计共用小标题规则：`12px / 16px / 600 / text`。中间区域统一上留白 `16px`，首个小标题距输入栏下分割线为 `16px`，不再叠加各视图自己的顶部留白。筛选组间距仍为 `20px`，组名保持 `12px / 400 / text`；“未限定时搜索全部字段”紧随筛选标题，以 `12px / 400 / muted` 显示，字段组通过 aria-describedby 关联。清空操作保持 `32px`（窄屏 `44px`）点击区域，围绕标题行延伸，不推移标题；无条件时禁用，布局保留。

本轮主流程 31 项浏览器检查通过，补充 6 项检查覆盖最近搜索记录、清空后的标题位置及矮窗口的键盘焦点。窄／矮视口的标题行按钮使用 `0px` 焦点外偏移，保留原宽度和颜色，完整焦点框落在滚动视口内。默认与筛选页在桌面、窄屏均为 `480px`，`1440×360` 视口下均收至 `336px`；大量结果保留原 `720px` 桌面上限。最终 `pnpm check` 通过类型检查、111 项测试及生产构建，独立界面复核为 ship。13 张本轮截图位于忽略的 `.impeccable/review/search-heading-height-2026-10-29/`；测试浏览器、控制进程及开发服务已关闭并复查退出。

选项与可移除条件共用同一 choice-chip 规则：`13px / 20px / 400`、`4px 12px` 内边距、选项及条件横纵间距 `12px`、桌面最小高 `28px`、窄屏至少 `44px`。类型、时间、字段复用 `ToggleGroup`，标签复用 `FacetFilter inline`，条件复用共享 `Badge choice`。默认使用 `surface-secondary / muted` 与 `0.5px border-default` 内描边，未选悬停为 `surface-subtle / text`；筛选面板编辑控件在深浅主题选中时使用 `accent-soft / accent-ink`，匹配页头当前“筛选”按钮，去除默认描边、边框和阴影，选中悬停为 `tag-surface-hover / accent-ink`。这组控件选中 token 与卡片标签的 `accent-primary-bg` 悬停 token 分开。键盘焦点保留 `2px accent-ink` 外框及 `2px` 偏移；胶囊显式使用 `corner-shape: round` 保留半圆端部。组件保留键盘、禁用及高对比状态。

| 组 | 选择规则 | 查询含义 |
| --- | --- | --- |
| 类型 | 网站、文章、关注源，可取消单选 | 无选中即全部；始终只有一个范围，不与星标／未处理交叉 |
| 时间 | 今天、过去 7 天、过去 30 天、今年，可取消单选 | 无选中即不限；按收藏时间 `createdAt` 和用户本地日历计算 |
| 标签 | 已有标签可多选 | 按稳定 ID 精确匹配，多个标签必须同时满足；候选及对应结果条件显示 `#`，横向滚动，无额外弹层或候选计数 |
| 搜索字段 | 标题、描述、标签、域名、快照正文，可多选 | 所选字段为 OR；未选或选满为全部，明确提示“未限定时搜索全部字段” |

没有标签时不渲染对应空组。快捷视图只从侧栏调用，不在搜索中重复展示。星标与未处理仍可从侧栏浏览，但不作为搜索类型选项恢复。

标签横向滚动复用共享 ScrollArea 原生 viewport，隐藏原生横向滚动条，显示 `4px` DOM 滑块；指针轨道高 `12px`，溢出时稳定留 `8px`。闲置不绘制，标签模块 hover、键盘可见焦点或拖动时显示，悬停和拖动分别用 scrollbar-thumb-hover／active；无悬停布局跳动。指针捕获支持滑块拖动，触控板、触屏和键盘继续滚动原生视口。前缀 `#` 仅在本面板的实际标签候选及其可移除条件添加，类型、时间、字段名称不加前缀；标签 ID、名称、搜索和持久化不变，其他页面沿用无前缀规则。

时间以本地零点为开始：今天从今日零点，过去 7 天从今天前 6 天零点，过去 30 天从今天前 29 天零点，今年从 1 月 1 日零点起，终点均为当前时刻；已限定查询排除未来日期记录。7 天与 30 天均包含今天，按自然日而非固定毫秒计算，跨夏令时仍保留本地零点。URL 和最近搜索保留原 `week` 键，恢复后统一表示过去 7 天。字段“标签”匹配标签文字，精确标签组筛选标签身份，两者可以同时生效。多个关键词必须全部命中，允许分布在所选字段并集中；无关键词时字段本身不排除收藏。

字段不再有“全部字段 / 标题及描述”预设按钮或最后一项禁用。旧 URL 和历史中的 `title-description` 在读取边界展开为标题与描述；空值、未知值或选满五项规范化为 `all`。

## 清除、快捷视图与历史

- 输入 X 只清关键词，保留类型、时间、标签和字段。
- 胶囊再次点击取消自身选择；取消最后一个字段恢复默认全部。
- 结果页 Badge 只移除对应类型、时间、标签或字段；移除后回焦主输入。
- “清空筛选”重置类型为全部、时间为不限、标签为空、字段为全部，并清除当前快捷视图标记；保留关键词。
- 最近搜索的清空操作仅清除搜索历史，不删除收藏或最近打开。

快捷视图定义仍只保存范围与标签，不增加关键词、时间、字段、排序或排列。搜索已移除快捷视图组，但现有视图关联不变：手动改范围或标签立即解除标记，仅改关键词、时间或字段可以保留；显式提交时只保留与草稿范围、标签集合完全一致的视图。直接侧栏切换仍清空临时标签、恢复最新排序，保留关键词、时间与字段；从侧栏调用快捷视图应用范围、标签并恢复最新排序。

最近搜索只在显式提交完整结果时记录，最多保留 6 条，面板展示其中兼容范围的最近 3 条。按规范化关键词、范围、实际字段、标签集合和时间条件去重；恢复时同时恢复这些可见约束。旧字段可兼容，缺失时间视为不限，旧标签 ID 不再被清空。没有关键词、具体范围、时间或标签的记录不保存，单独限定字段不构成有效空查询；纯标签或纯时间可以保存。旧星标、未处理记录留在存储中但不显示恢复入口。存储失败不阻断查找。

## 草稿、预览与提交

打开面板复制工作台已生效关键词、字段、时间及生效标签；全部或内容类型范围直接继承，星标／未处理范围转换为全部。原工作台和 URL 在编辑过程中保持原状态。

点击结果或在输入导航中按 Enter 只预览详情。搜索与详情互斥渲染，不叠加焦点陷阱；详情的“返回搜索”或 Esc 恢复同次草稿、活动结果、筛选页状态和列表位置。返回按钮保持共享 ghost 外观，无 Tooltip，窄屏可仅显示箭头并保留完整可访问名称。预览内编辑、星标或删除继续保存真实业务变化，不等于提交搜索。

只有“查看全部结果”或结果页内的 `⌘Enter / Ctrl+Enter` 一次提交关键词、范围、时间、标签、字段，更新工作台和 URL，回到结果顶部；有关键词默认按最相关排序，无关键词按最新，排列方式保留。取消搜索则恢复打开前工作台条件和滚动位置，不保存未提交草稿。预览不写工作台 item URL 或最近搜索。

## 查询、键盘和反馈

普通输入即时回显，最后一次输入后 `200ms` 查询。输入法组合期间不查询、不提交或预览；组合结束后按最终文本防抖。切换条件及恢复历史立即查询当前完整草稿；显式提交立即执行排队查询，过期结果不得覆盖最新结果。更新时显示“正在更新…”，旧结果不可打开，计数及提交按钮不沿用旧数字；失败显示重试而非零结果。

检索沿用 MiniSearch：精确标题或域名优先，然后按标题 5、标签 4、描述 3、域名 2、正文 1 的权重与匹配分数排列；平分时按较新收藏及稳定 ID 排序。所有关键词必须匹配，不在零结果时悄悄放宽。归档排除、中文分词、英文前缀和受限拼写容错保持现有边界。

| 按键 | 行为 |
| --- | --- |
| `⌘K / Ctrl+K` | 工作台打开搜索；其他任务 Modal 或编辑器上下文不被劫持。面板内回焦主输入 |
| `↑ / ↓` | 输入导航时改变活动结果；在筛选控件中由共享控件管理 |
| Enter | 输入导航时预览活动结果；筛选页主输入中确认当前筛选草稿并返回结果 |
| `⌘Enter / Ctrl+Enter` | 筛选页确认条件并回结果；结果页显式提交当前完整草稿 |
| Tab / Shift+Tab | 在输入、清词、筛选、条件移除、结果页关闭及提交之间移动 |
| Esc | 详情返回搜索；筛选页取消本次条件更改并回结果；默认／结果页取消整个搜索 |

Dialog 名称为“搜索收藏”，输入有独立标签，图标按钮有可访问名称；活动结果和列表使用共享 Command Menu 的虚拟焦点及可访问机制。输入法组合期间 Enter、Esc、方向键留给系统候选行为。结果统计使用 polite live region，不把失败播报成空结果。

零结果保留当前词和条件；有非默认条件时提供清空筛选，不自动扩大范围。仅正文查询说明只搜索已保存的快照，不触发抓取或要求 AI。长内容、低高度和窄屏保持一个纵向滚动中间区及可操作顶栏；动效复用现有组件和 reduced-motion 行为，不新建搜索专属动画。
