# Wispora

<img src="public/assets/brand-lockup.svg" alt="Wispora" width="316" height="80" />

Wispora 是面向设计与开发工作的本地优先灵感库浏览器扩展，用于收藏、整理并重新发现网站、文章与关注源。

支持 Chrome 和 Edge：从当前网页或 URL 添加内容，通过星标、标签、快捷视图与本地全文搜索重新找回收藏，并保留可阅读的正文快照。数据保存在当前浏览器，无需账户或后端；AI 整理可选，未配置 AI 时仍可正常收藏、编辑和搜索。

代码仓库：[leoyug/Wispora](https://github.com/leoyug/Wispora)。

## 本地开发

```bash
pnpm install
pnpm dev
```

开发环境默认使用空的本地收藏库。如需显式导入演示数据，打开 `dashboard.html?seed=demo`；生产构建不会触发该种子逻辑。收藏项、标签、快捷视图和后台任务保存在浏览器 IndexedDB 中。

开发服务器启动浏览器后，打开任意 `http://` 或 `https://` 页面，点击工具栏中的 Wispora 图标即可在网页右上角打开快速收藏面板。扩展会保存页面元数据、经过清理的正文快照和可用封面；手工添加的链接会先保存为待补全，不会申请全站访问权限。浏览器内部页面等禁止脚本注入的页面会改为打开收藏库。

Dashboard 搜索覆盖标题、描述、域名、标签与正文快照。打开收藏项详情后，可阅读本地快照，编辑标题、描述、标签和封面，或删除收藏项；标签的重命名、合并和删除位于“设置 → 管理标签”。搜索、范围、标签、排序、排列和当前详情会同步到地址栏，刷新后可恢复。

## 本地备份与恢复

在 Dashboard 的“设置 → 备份与恢复”中下载 JSON 备份文件。备份包含收藏项（包括归档项）、标签、正文快照、用户封面、快捷视图及后台任务；文件保存在你选择的本地位置，不会上传到 Wispora。恢复时先选择文件并核对数量，再点击“确认合并恢复”。相同内容类型和规范化网址的已有收藏项会跳过，现有内容不会被覆盖或清空。备份文件包含私人收藏与网页正文，请妥善保管。

AI API Key 和 Provider 设置不包含在备份中；迁移到新的浏览器配置文件后需要重新配置 AI。建议在升级、卸载或更换设备前先导出备份，并妥善保存多个历史副本。

运行完整质量检查：

```bash
pnpm check
```
